## The project in one sentence
A custom investment dashboard called **Texas Global Investments**, Bloomberg-terminal-inspired, in navy, brown, and gold, for researching stocks, following markets, and eventually paper trading and backtesting.

## Tech snapshot
- **App:** Next.js 16 (Turbopack), originally generated by v0, code hosted on GitHub (repo named like `v0-next-js-app-setup`)
- **Machine:** Dell laptop, Windows, project folder at `C:\Users\steve\Documents\v0-next-js-app-setup-1`
- **Package manager: npm only.** `pnpm-lock.yaml` has been deleted — it was a stray leftover and is no longer used. `package-lock.json` is the real lockfile.
- **Structure:** a single-page app — `app/page.tsx` swaps the middle content when a menu item is clicked. The `app` folder contains only `globals.css`, `layout.tsx`, `page.tsx`. Reusable pieces go in the `components` folder.
- **14 menu sections:** Stocks (done — see below), Charts, Screener, Watchlists, Backtester, Paper Trading, Markets, Options, Forex, Crypto, Metals, Library, Games, Chapel — all still placeholders with fake numbers except Stocks.
- **Data plan:** TradingView's free embeddable widgets for charts and live prices (no API key, no cost), free stock-data APIs later where needed.
- **To run the dashboard:** open VS Code → File → Open Recent → the project → Terminal → `npm run dev` → browser to `localhost:3000`. Stop with Ctrl + C.
